# Documentation Management

All project documentation is centralized in the `./docs/` directory:

```
./docs/
├── project-overview-pdr.md
├── system-architecture.md
├── code-standards.md
├── codebase-summary.md
├── design-guidelines.md
└── agent-workflow.md
```

## Maintenance Rules
- Keep `AGENTS.md`, `CLAUDE.md`, `.clinerules`, and `./docs/` aligned when structure changes.
- Update `system-architecture.md` whenever database schema, OCR engine, or provider structure changes.
- Update `codebase-summary.md` when new features or files are added.
