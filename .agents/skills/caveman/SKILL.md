# Caveman Communication Mode

When activated, summarize technical findings, test results, and task progress concisely:
- Omit unnecessary fluff and boilerplate explanations.
- Bullet points over long prose paragraphs.
- Highlighting key metrics, changed files, and test pass/fail status.
- End reports with unresolved questions if any exist.
